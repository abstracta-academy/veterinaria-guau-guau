# Veterinaria Guau Guau

Sitio web ficticio de una veterinaria, creado por Abstracta Academy como material de práctica para cursos de testing de software.

Todos los datos que se muestran son inventados. No contiene información real de personas, mascotas ni clínicas.

## Qué es

Una aplicación web simple para gestionar los clientes de una veterinaria, sus mascotas y las vacunas de cada una.

## Qué se puede hacer

- Iniciar sesión.
- Registrar clientes con sus mascotas y vacunas.
- Agregar o editar mascotas de un cliente ya registrado.
- Consultar la lista de clientes, la de mascotas y la ficha de cada mascota.

## Uso

Este sitio es de uso educativo. Los datos que se cargan se guardan solo en el navegador de quien lo usa, no en ningún servidor.
